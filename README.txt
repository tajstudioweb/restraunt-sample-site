TAJ STUDIO — RESTAURANT WEBSITE DEMO

A responsive, static restaurant website sample intended for the TAJ STUDIO ₹1,200 package.

PREVIEW
Open index.html in a browser. The website uses external Unsplash food/restaurant photography and Google Fonts, so an internet connection is required for those assets.

CUSTOMISE BEFORE DELIVERING TO A CUSTOMER
1. Replace every instance of {your brand name} with the customer's actual restaurant name.
2. Replace the demo logo mark {Y} with the customer's initials or logo.
3. Replace the sample menu items, descriptions and prices.
4. Replace the placeholder address, phone number, Instagram handle and email.
5. Update the telephone link in the contact section.
6. Replace the demo photography with the customer's own photos where available.

PUBLISHING
Upload index.html, style.css and script.js to the root of a GitHub Pages repository. No build step is required.

This is a demonstration template. Confirm all business details and prices with the customer before publishing.
